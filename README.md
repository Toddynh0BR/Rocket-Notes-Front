
# RocketNotes

RocketNotes é um bloco de notas online com o ituito de permitir aos usuarios que guardem suas anotações na nuvem de forma dinamica e simples. Possui diversar funcionalidades tais elas como login e criação de conta, buscar nota por nome ou filtra-las por
tags, edição de perfil e etc.

## Páginas

### Home

-Onde o usuário podera visualizar suas notas, buscar notas por nome ou filtra-las por tag.

### Preview

-Página de preview de nota para pode visualizar cada nota ou exclui-la

### User

-Página de visualização das informações do perfil, onde o usuário podera atualizar e ver suas informações,são elas, foto de perfil, nome, email e senha.

### CreateNote

-Página para criação de notas com 4 inputs diferentes, Nome, Descrição, Links e Marcadores(tags).

## Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/Toddynh0BR/Rocket-Notes-Front.git
```

Acesse o diretório do projeto:

```bash
cd RocketNotes
```
Instale as dependências:
```bash
npm install
```
Inicie o servidor de desenvolvimento:
```bash
npm start
```
Sinta-se à vontade para contribuir com o projeto.
